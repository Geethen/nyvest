Best DNN — temporal robustness, all-pseudo-label training & conformal UQ

Three follow-up investigations on the current best model (the ensembled class-weighted MLP, macro-F1 0.7341, documented in dnn_replacement_report.html). All three reuse the identical base learner (5-seed MLP ensemble, sqrt class weights, label smoothing, train-only cls12 centroid clean) and the same 64 AlphaEarth + 3 lidar features, and are strictly leak-free. Headline: the model is temporally robust (−0.009 macro-F1 under leave-year-and-block-out), keeping all uncertain pseudo-labels doesn't help (+0.0003, a no-op), and among conformal methods LAC gives the tightest prediction sets while class-conditional (Mondrian) calibration fixes the per-class coverage gap that plain APS leaves on rare classes.

1 · Temporal robustness — leave-location-AND-time-out (LLTO)

The headline number is from spatial 3-fold CV, which mixes all acquisition years into both train and test. That never tests generalization to an unseen year — a real risk because AlphaEarth embeddings can drift year to year (sensor, phenology, processing). LLTO holds out both axes at once: for each year 2017–2025, the test set is (that year) ∩ (a held-out spatial cell_id block), and the training set excludes both that year and that block. A test pixel is therefore unseen in time and space. This is strictly harder than either axis alone.

ProtocolMacro-F1vs headline spatial CV
Spatial-only CV, all years mixed headline protocol0.7302— (matches report's 0.7318)
LLTO — leave-year-and-block-out (mean over 9 years)0.7210−0.0092
The model is temporally robust. Adding a full temporal hold-out on top of the spatial block costs only −0.009 macro-F1 (0.7302 → 0.7210) — barely above one fold's std (±0.006–0.018). Predicting on a completely unseen acquisition year, in unseen locations, the model still scores 0.721. There is no temporal collapse: the model has not overfit any single year's radiometry.

2 · Train on ALL pseudo-labels — no uncertainty removal

The Scheme B / stage-4 approach only adds unstable rows whose CC-APS prediction set is a singleton (the confident ones). The question here: does keeping every unstable row — uncertain ones included, each tagged with the ensemble's argmax pseudo-label — help? Three arms, identical base learner, same leak-free spatial CV, test labels untouched. The unstable parquet (16,844 rows, the transition/edge pixels that fail the temporal-stability filter) is the pseudo-label pool.

Armpseudo rows / foldpseudo-label accMacro-F1Δ vs control
none — stable train only control (headline)0—0.7310—
singleton — CC-APS confident only stage 4~5,2700.8890.7320+0.0010
all — every row, argmax, no filter16,8440.6900.7313+0.0003
Keeping the uncertain rows is a no-op, but — importantly — it does not hurt. Adding all 16.8k unstable rows with argmax labels moves macro-F1 by +0.0003 (0.7310 → 0.7313), inside the ±0.01 fold noise, even though pseudo-label accuracy drops from 89% (singleton) to 69% (all). So the confident-filter's job isn't protecting the model from bad labels here — the model is robust to the ~31% wrong pseudo-labels because they're outnumbered ~40:1 by real stable data. The reason neither arm helps is the same structural ceiling from the best-model report: the bottleneck is feature-space class overlap, not data quantity — the unstable pool lives in exactly the overlapping regions that no amount of (correct or incorrect) extra labels can separate. Per-fold both pseudo arms track the control within ±0.002 on every fold, confirming this isn't averaging out a real signal.

Practical read: if you want the unstable/transition pixels labelled anyway (e.g. for a wall-to-wall map), you can pseudo-label all of them with the argmax and pay no macro-F1 cost — the confident-only filter buys nothing on accuracy. But do not expect self-training on this pool to raise the ceiling.

Do the pseudo-labels help the harder case — TEMPORAL robustness? (LLTO × pseudo)

A no-op under spatial CV doesn't rule out a temporal benefit: the unstable pool is exactly the transition/edge pixels, which could plausibly help generalize to an unseen year even if they don't help spatially. So we re-ran the full leave-year-and-block-out protocol (§1) with all pseudo-labels added, head-to-head against the no-pseudo control. Leak control: unstable rows from the held-out year are dropped, so no test-year data enters training. The control arm reproduced the standalone LLTO number (0.7210) exactly — the crossing is valid.

No — adding all pseudo-labels does not improve temporal robustness. LLTO macro-F1 is 0.7206 vs 0.7210 (Δ = −0.0004, a no-op within noise), and the two arms are identical to two decimals on every class, including class 12. Crucially, snow/ice's temporal fragility is unchanged: its per-year F1 spread is 0.239 (all) vs 0.251 (none) — pseudo-labels neither help nor hurt the one class that drives the whole temporal penalty. This is expected: the temporal gap is snow/ice, and the unstable pool contains no snow/ice signal (it is transition/edge pixels in the overlapping classes), so it has nothing to contribute where it is needed. Per-year, the `all` arm tracks the control within ±0.0012 across all 9 years, including the weak 2020 (0.6999 vs 0.6992). The pseudo pool is a no-op on both the spatial and the temporal axis.

2c · Train on 2018 only, deploy forward — the "label once" scenario

The headline model pools 8 training years. In practice you often label one year and apply the model forward to later years. Does a 2018-only model hold up on 2019–2025, and how much does training on a single year cost versus the all-years model? Same spatial blocks as §1 (so the spatial-generalization penalty is identical — the only change is the training years), leak-free, headline recipe. The all-years LLTO column is the §1 model (trained on the other 8 years, tested on the same held-out year+block), so the delta isolates "1 training year vs 8".

The all-years (8-year) model beats the 2018-only model on every forward year — by ~0.020 macro-F1 on average (0.7026 vs 0.7230). Two effects stack:
  • A one-time forward-transfer drop: 2018-only scores 0.7269 in-year but 0.7026 averaged over 2019–2025 — a −0.024 hit for deploying onto any unseen year. It appears immediately at +1y (0.714) and does not keep decaying monotonically with horizon (2021–2024 sit ~0.705–0.713); the low point is 2020 (0.668, the intrinsically hard snow year), not 2025.
  • A persistent single-year penalty: even ignoring drift, one year of training data (~74k rows) vs eight (~590k) costs ~0.020 on forward years. This is the price of 8× less training data and the diversity of seeing multiple years' radiometry.
Per-class, the forward drop mirrors the fragility ranking: snow/ice −0.07, grassland −0.05, wetland −0.04 take the hit; water/cropland/forest/infra barely move (≤ −0.01). So a 2018-only model is usable forward (still ~0.70) but leaves ~0.02–0.025 on the table versus pooling years, concentrated in exactly the hard classes.

Answer to "does it perform better than a 2018-only model deployed forward?": yes — the all-years model is better on all 7 forward years (mean +0.020), and the gap widens on the fragile classes. If only one labelled year is available, expect ~0.70 forward (vs 0.72–0.73 pooled), with a hard floor on snow-variable years like 2020. Pooling multiple training years is the cheap win.

3 · Conformal uncertainty methods

The pipeline uses APS both for pseudo-labelling and as its uncertainty notion. This benchmarks 5 conformal score functions × 2 predictors on the headline ensemble, all at target coverage 90% (α=0.10), plus temperature scaling for point uncertainty. Leak-free: the ensemble is trained on the other spatial folds; within the held-out fold, half calibrates τ and half evaluates. Metrics — marginal coverage (should ≈ 0.90), average set size (smaller = more informative), singleton rate, and per-class coverage spread (max−min over classes; the fairness gap APS leaves on rare classes).

All methods achieve the target 90% marginal coverage (calibration is valid). Differences are in efficiency (set size) and class-conditional fairness (coverage spread).

Two clear, complementary recommendations:
  • For the tightest / most decisive uncertainty → LAC + split. Smallest average set (1.40 classes vs APS's 1.68), highest singleton rate (65%), and zero empty sets. If the downstream use is "flag the pixels the model is unsure about" or a confident pseudo-label gate, LAC dominates the current APS on every efficiency axis.
  • For fair per-class guarantees → any score + Mondrian (class-conditional). Plain split calibration leaves a per-class coverage gap of 0.21–0.29 (rare classes like snow/ice are systematically under-covered — the sets miss the true class more often than the 10% budget allows). Class-conditional calibration collapses that gap to 0.03, restoring the coverage guarantee for every class, at the cost of larger sets. LAC + mondrian is the sweet spot: 0.035 spread at a still-modest 1.64 set size.

Why APS looks worst here: APS and SAPS are the only methods that produce empty sets (2.6% / 4.4%) — rows where even the top class exceeds τ — which is an efficiency (not validity) artefact of the randomized cumulative score, and they carry the largest split-predictor sets among the non-Margin scores. The pipeline chose APS for its adaptivity, but for this problem LAC's simple 1 − p̂[y] threshold is both tighter and empty-set-free.

Point uncertainty — temperature scaling

Beyond set-valued conformal, a single scalar confidence is often wanted (for map shading, triage). The ensemble's max-probability is slightly mis-calibrated; a single temperature T fit on the calibration half corrects it.

mean TECE beforeECE afterreduction
5-seed ensemble max-prob0.780.0690.039−43%

Fitted T ≈ 0.78 < 1 means the ensemble is mildly under-confident (averaging 5 softmaxes flattens the peaks); sharpening by T halves the calibration error (ECE 0.069 → 0.039). Recommendation: apply a single temperature (fit on a held-out slice) before using ensemble probabilities as confidence scores or as the input to any conformal method — it's free and improves both calibration and downstream set sizes. Mean OOF accuracy was 0.786.

Overall conclusions

  • Temporally robust. Under the strict leave-year-and-block-out protocol the model loses only −0.009 macro-F1 (0.730 → 0.721); per-year F1 sits in 0.700–0.734 with no decay toward newer years. Safe to deploy on a future year's AlphaEarth.
  • Pool your training years. A 2018-only model deployed forward scores ~0.703 mean over 2019–2025 vs 0.723 for the all-years model — the 8-year model wins on all 7 forward years (+0.020 mean), and the gap concentrates in the fragile classes (snow/ice −0.07, grassland −0.05). A single-year model is usable (~0.70) but pooling years is the cheap win.
  • Snow/ice is the single fragile class on both axes. It carries the entire temporal penalty (0.24 F1 spread across years, crashing in 2020) and remains the label-noise-limited class from the best-model report. Any further effort should target class 12 specifically — better/fresher glacier labels or a temporal-consistency constraint — not the model.
  • More pseudo-labels won't raise the ceiling — on either axis. Training on all 16.8k unstable rows (69% pseudo-accuracy, no uncertainty removal) is a no-op under spatial CV (+0.0003) and under the harder temporal LLTO hold-out (−0.0004), leaving even snow/ice's temporal fragility unchanged. The ceiling is feature-space overlap; extra labels in the overlap regions can't move it. Upside: you can pseudo-label the transition pixels at no accuracy cost if you need a complete map.
  • Switch conformal method by use-case. Use LAC + split for the tightest confidence/pseudo-label gate (1.40 vs APS 1.68 set size, no empty sets); use Mondrian (class-conditional) calibration whenever per-class coverage guarantees matter (spread 0.29 → 0.03), with LAC + Mondrian the best balance. Always temperature-scale (T≈0.78) the ensemble probabilities first — ECE drops 43%.
