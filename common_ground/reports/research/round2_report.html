4. Findings, recommendations and next ideas

What we learned

  • high_iter (1 000 rounds) remains the only macro-F1 winner. No round-2 experiment beats it. Δ = +0.0047 over baseline, with the lowest fold-level σ (0.0168). Going further to 1 500 rounds (high_iter_1500) hurts macro-F1 (Δ = −0.006) and roughly doubles fold variance: fold 0 gains (0.629), fold 1 is flat (0.648), fold 2 collapses (0.565) — classic overfitting.
  • high_iter_cw_targeted is the most interesting new result. 1 000 iter + 3× weight on weak classes {1,2,5,6,7} sits at F1 = 0.6181 — within fold noise of baseline and statistically a tie with high_iter, but it lifts class 1 (F1 = 0.099 vs 0.038, +0.061), class 2 (0.582 vs 0.548), and class 5 (0.412 vs 0.364). The macro number doesn't move because gains on minorities are offset by losses on classes 4 and 6. It's the best operating point if minority recall matters.
  • pseudo_top80 is a clean tie with baseline (Δ = −0.0015). Dropping 80% of pseudo-labels yields essentially the same macro-F1, confirming the cg_llto = cg_llto_raps tie from the original validation — pseudo-label quantity is not the bottleneck.
  • XGBoost on GPU is competitive but not better. F1 = 0.6121 puts it close to CatBoost defaults; fold variance is higher (σ = 0.0338) and it does win fold 1 outright (0.6542). A tuned XGBoost is worth keeping as a comparison baseline, not a primary model.

What did not work

  • l2_leaf_reg=10 collapses everything. F1 = 0.569, σ = 0.049 — way too much regularisation. Default CatBoost L2 (=3) is already well tuned.
  • depth=8 underperforms default depth=6. Δ = −0.011. Deeper trees overfit the noisy pseudo-labels.
  • high_iter_cw_full (full inverse-freq weights at 1 000 iter) underperforms both ingredients individually. Stacking class weighting with more rounds did not compound benefits — the weight scheme over-corrects on rare classes once trained longer.
  • pseudo_class5_strict (confidence ≥ 0.70 only for class 5) hurts. Δ = −0.008 macro, and class-5 F1 itself only moves marginally. The model still confuses class 5 with 3/4 even when restricted to high-confidence pseudo-labels — confirming the problem is intrinsic feature overlap, not pseudo-label noise.
  • high_iter_1500 overfits. The 1 000-iter sweet spot is real; pushing further destabilises fold 2 specifically (the fold with the fewest unstable training rows).

Operating-point recommendation

For macro-F1: use high_iter (CatBoost 1 000 iter, no weights).
For minority-class recall (classes 1, 2, 5): use high_iter_cw_targeted (1 000 iter + 3× weight on {1,2,5,6,7}). Trades ~−0.006 macro-F1 for substantial gains on the three hardest classes.
For label-noise robustness: use pseudo_top80 (drop bottom-80% confidence pseudo-labels) — same macro-F1, smaller training set, faster.

Next ideas (still untried)

  • high_iter_cw_targeted with class-5-only weight = 5×. Class 5 is the worst offender for macro-F1 ceiling (mean 0.364). A surgical single-class boost might lift it without sacrificing class 4/6.
  • Two-model ensemble: high_iter for majority + high_iter_cw_targeted for minority. Predict with both, take cw_targeted's prediction only when it returns one of {1,2,5}. Cheap to evaluate, exploits each model's strength.
  • Pseudo-label class re-balancing. The unstable set's pseudo-label distribution is heavily skewed toward majority classes (because Stage 1 already over-predicts them). Cap pseudo-labels per class at min(N, 2 × stable_count). Doesn't oversample — it down-samples the over-represented pseudo classes only.
  • Stage 1 trained only on weakly-confused features. Drop the bottom-decile mutual-information bands and re-train. Reduces dimensionality from 64 → ~58 and may help class 5 specifically.
  • CatBoost auto_class_weights="Balanced". A built-in CatBoost weighting that's schema-aware and may behave better than the manual inverse-frequency vector tested here.
