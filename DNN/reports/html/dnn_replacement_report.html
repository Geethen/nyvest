DNN replacement for the CatBoost + TabICL pipeline

A single GPU neural network that replaces the two-stage CC-APS CatBoost → TabICL model on the nyvest land-cover task. Evaluated on the identical protocol as the Scheme B all-years report (same stable all-years AlphaEarth + lidar features, same class merges, same spatially-blocked 3-fold CV, same untouched-test macro-F1). Best macro-F1 0.7341 — +0.0202 over the TabICL+lidar reference (0.7139), and it trains in ~6 min on one A40 vs the ~38 min two-stage pipeline, using <2 GB of GPU memory. This report supersedes the Scheme B report as the current best model.

DNN/data_utils.py — mirrors llto_schemeB_allyears.py exactly (merge 1→2 / 9→8, GroupKFold on cell_id, macro-F1 over all classes, lidar join, leak-free test).

data/grunnkart_nyvest_fscs_stable_allyears_alphaearth.parquet — 663,740 rows, 2017–2025
Features
64 AlphaEarth bands (A00..A63) + 3 lidar terrain features (elevation, tri, tch) — the same set the Scheme B report established as best
Target
class — FSCS land-cover, 10 classes after merging 1→2 (bare) and 9→8 (marine→water)
Validation
Spatially-blocked 3-fold CV (GroupKFold on cell_id); macro-F1 on untouched (noisy) test labels
Architecture
2-layer MLP (256→128, ReLU, dropout 0.3), sqrt-tempered class-weighted cross-entropy + label smoothing 0.05, Adam, early stopping, 5-seed probability ensemble; train-only class-12 label handling (centroid clean / targeted relabel)
Hardware / runtime
NVIDIA A40 (24 GB); ~270 s (best MLP) – ~370 s (with cls12 relabel) for all 3 folds. <2 GB GPU — no support-size ceiling.
Date
2026-06-29 (DNN stages 1–9, noise diagnostics, MoE); 2026-06-30 (report)
Why this report exists. The Scheme B all-years report documents the CC-APS CatBoost → TabICL pipeline up to F1 0.7139 (32k support + lidar). This session built a DNN to replace that pipeline. A deliberately incremental search (plain MLP → regularized → architecture sweep → MoE → pseudo-labelling → label-noise correction → attention) found that a simple class-weighted ensembled MLP beats the two-stage pipeline, and a targeted class-12 label fix pushes it to 0.7341. A parallel session that extracted NiN_v2 field labels as extra training data is summarised below — it did not help.

The one structural finding: the ceiling here is spatial generalization + feature-space class overlap, not model capacity. Stage 2's residual net hit validation-F1 0.965 while test-F1 stayed 0.71 — it memorizes the training fold but does not transfer across the geographic cell_id folds. Every attempt to add capacity (depth, GLU, SNN, FT-Transformer, class-MoE, spatial-MoE, feature-attention) underperformed a simple ensembled MLP. The only levers that ever moved macro-F1 were better features (the lidar terrain bands, established in the Scheme B report) and variance reduction (the 5-seed ensemble).

Four leak-free tests (transition matrix, confident-disagreement, noise-corrected ceiling, and clean-vs-noisy F1 gain) reusing the per-fold cleanlab artifact clean_labels_perfold.npz. The decisive test retrains on leak-free corrected labels and reads the per-class F1 change.

Label noise is a real, fixable problem for exactly one class — snow/ice (12). Its labels are systematically stale: 29 of 146 unique snow/ice locations look like another class in every embedding year 2017–2025 (no temporal trend), i.e. permanently mislabelled rock/debris polygons that deglaciated before the embeddings — both the noise estimate and the model vote point to infrastructure (class 11), the same 21–23% leak the pipeline's confusion matrix shows. Correcting cls12 labels lifts it +0.037 in isolation. For the genuinely worst classes (grassland, bare, wetland), relabeling makes them worse — cleanlab recodes real grassland as forest because the classes overlap in feature space. They are confusion-bound, not noise-bound. Applying the correction to ALL classes hurts the DNN macro-F1 (−0.0065), so the winning config relabels class 12 only.

Macro-F1 saturates by ~70% of the data and even dips slightly at 100%. The worst classes (grassland, bare) are dead flat across the curve — confusion-bound, not data-starved. NiN_v2 field labels as extra training data — no gain

A parallel session extracted the NiN_v2 ("Natur i Norge", field-mapped nature types, 28,496 polygons surveyed 2018–2023, higher certainty than grunnkart) as candidate extra training data for the problem classes, via a naturtype→FSCS crosswalk → points → AlphaEarth extraction (scripts/extraction/nin_*.py, data/nin_alphaearth.parquet, 200,006 rows).

NiN_v2 adds no real gain — do not add it to training. Naively adding all points hurts (−0.0073); the best class-balanced variant is +0.0013, well inside the ±0.005 RNG band. Cause (confirmed by centroid diagnostic): NiN's fine ecological types don't align with grunnkart's coarse FSCS classes in AlphaEarth space — a label-definition mismatch, not a quality win. NiN heathland (Kystlynghei) sits closer to grunnkart grassland than to grunnkart's own scrub centroid, and NiN myr (wetland) closer to grassland than its own wetland — so injecting them corrupts exactly the boundaries we want to fix. Critically, NiN has no snow/ice category, so it cannot help class 12 — the one class with fixable label noise. The only honest path forward would be to relabel grunnkart pixels under high-certainty NiN polygons (overwrite, not append a second taxonomy), or build a NiN→FSCS map validated in embedding space.

What moved the needle — and what didn't

  • The DNN replaces the pipeline and wins. A class-weighted 2-layer MLP + 5-seed ensemble reaches 0.7318 — already above TabICL+lidar (0.7139) — on the same features and CV, in a fraction of the time and memory.
  • Ensembling is the reliable lever; augmentation is not. 5-seed probability averaging is worth ~+0.004 (single seed 0.7248 → ensemble 0.7318). mixup and input noise were tried and dropped (they slightly hurt). Architecture (residual/GLU/SNN/FT-Transformer), class-MoE, spatial-MoE, conformal pseudo-labelling and feature-attention all failed to beat the plain MLP.
  • Targeted class-12 relabel is the only class-specific win (+0.0023 macro, +0.024 on cls12). Surgically relabeling stale snow/ice rows banks the cls12 gain without the −0.0065 macro damage that blanket relabeling causes.
  • The bottleneck is feature overlap, not the model. Learning curves saturate by 70% of the data; cleanlab confirms grassland/bare/wetland are confusion-bound. More data, more capacity, and routing (MoE) cannot separate genuinely-overlapping classes.
  • Feature-attention weights independently re-rank lidar (tri, tch, elevation) as the top features — corroborating the Scheme B lidar finding by a second method, even though acting on the weights doesn't raise F1.
  • NiN_v2 field labels don't help (label-definition mismatch; no snow/ice class).
